# Four Seasons Frontier

Godot 4 prototype for a 45-degree 2D farming, building and exploration game.

## Run

Open this directory in Godot 4 and run the main scene. The current prototype draws an isometric farm grid and supports movement with WASD or arrow keys, farming tools (1–4), building (B), removal (X), and day advancement (N), save (F5), and load (F9).

The player marker is intentionally temporary. Processed production assets are under `assets/processed/`; the next milestone is replacing the marker with the farmer sprite and adding farm interactions.
